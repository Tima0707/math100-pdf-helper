# v1.2.0 — первый публичный выпуск

- Скачивание доступного PDF Math100 по нажатию на значок.
- Название файла из заголовка страницы; безопасные имена и обработка дубликатов.
- Проверка домена PDF и сообщение при нескольких найденных документах.
- Удалены встроенные ссылки на конкретные учебные материалы.
- Лицензия MIT на код, инструкция по установке и описание разрешений.

Скачайте math100-pdf-v1.2.0.zip, распакуйте и загрузите папку как распакованное расширение.
Работа проверена тестами логики; установка и фактическая загрузка в Яндекс Браузере не проверены.
