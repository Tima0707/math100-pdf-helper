# Math100 PDF Helper

Неофициальное расширение для сохранения доступного PDF Math100 по нажатию на значок.
Проект не связан с Math100 и не одобрен администрацией сайта.

## Установка

1. Скачайте `math100-pdf-v1.2.0.zip` из раздела Releases и распакуйте.
2. Откройте `browser://extensions` в Яндекс Браузере или `chrome://extensions` в Chrome.
3. Включите режим разработчика и нажмите «Загрузить распакованное расширение».
4. Выберите папку с `manifest.json` и закрепите значок расширения на панели.

Яндекс может ограничивать установку расширений вне магазина. Не отключайте защиту браузера.
Расширение рассчитано на настольные Chromium-браузеры с Manifest V3; работа во всех браузерах не проверена.
Firefox, Safari и мобильные браузеры не тестировались.

## Использование

Откройте страницу Math100, дождитесь документа и нажмите значок расширения.
PDF сохраняется в подпапку `Math100` в загрузках. Название берётся из заголовка страницы,
например: `ЗАДАНИЯ №10 РАЦИОНАЛЬНЫЕ УРАВНЕНИЯ И НЕРАВЕНСТВА.pdf`.
Текст самого PDF не анализируется. При открытии прямой ссылки имя строится из идентификатора файла.
Если найдено несколько PDF, откройте нужный отдельно. Если PDF не найден — также откройте прямую ссылку.

Значки: `↓` — загрузка запрошена; `?` — требуется прямая ссылка; `!` — ошибка.
Подробности отображаются при наведении. Завершение загрузки проверяется через Ctrl+J.

## Доступ и приватность

- `activeTab` — доступ к текущей странице после нажатия.
- `scripting` — поиск PDF и заголовка страницы.
- `downloads` — сохранение выбранного файла.

Нет аналитики, внешних библиотек, серверов проекта и фонового обхода сайта.
Запрос на скачивание направляется на `pdf.math100.ru` средствами браузера.
Разрешены только HTTPS PDF с этого домена. Ссылки на конкретные учебные файлы в проект не включены.

## Проверка и сборка

Нужны Node.js и Python 3. Внешние зависимости отсутствуют.

```sh
node --check background.js
node tests.cjs
python3 build.py
```

Архив появится в `dist/`. Проверки выполняются с имитацией браузерного API;
это не заменяет проверку установки и загрузки в реальном браузере.
